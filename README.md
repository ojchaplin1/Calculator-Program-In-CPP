# Calculator Program in C++

A simple, terminal-based 4-function calculator program built in C++, able to run once. This project allows users to perform basic arithmetic from the terminal.

## 🚀 How to Build and Run

Follow these terminal commands to get the application running locally on your machine:

```bash
# 1. Clone this repository
git clone https://github.com

# 2. Move into the project directory
cd Calculator-Program-In-CPP

# 3. Compile the source code into an executable
g++ main.cpp -o calculator

# 4. Launch the application
./calculator
```
*(Note: If your file is named something other than `main.cpp`, change `main.cpp` to your cpp src)*

## 🕹️ How to use program

Follow this format in the terminal after build:

```bash
# 1. When given the output, "Enter two numbers to calculate with arithmetic option in the middle:" Do this - number + number. Ex. 5 + 10

# 2. Make sure that you enter integer values, the calculator program will format the correct output for you.

# 3. Enjoy the output!
```
